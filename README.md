# Chain Memo (가제)

시험 문장을 **장면 단위 체인**으로 묶어, 매번 처음부터 다시 쓰며 한 줄씩 누적해 외우는 학습 앱.

- 타겟: 시험 준비생 (IELTS · TEF Canada · OPIc) — 스피킹 스크립트, 라이팅 모델 문장, 리딩 지문, 리스닝 대본의 문장을 체인으로 암기
- 언어: 영어 · 프랑스어 (데이터 구조는 언어 중립 — 추후 언어 추가 가능)
- 모든 콘텐츠는 각 시험의 형식·격식에 맞게 **자체 제작**

## 학습 방식

1. 체인을 골라 장면을 떠올리며 전체를 읽는다 (뜻·발음 제공 — 발음 속도 3단계 조절, 기기 음성 자동 선택, 해당 언어 음성이 없으면 추가 방법 안내)
2. 누적 학습: 뜻만 보고 **처음부터** 한 줄씩 다시 쓴다. 단계가 오를 때마다 끝에 새 줄이 하나 붙는다
3. 막힌 줄은 기록되어 다음 회차에 다시 걸린다 — 복습이 구조에 내장돼 있다
4. 접근성: 모든 버튼·칩 터치 영역 44px 이상, 보조 텍스트 대비 강화, 키보드 focus 표시, 동작 줄이기(reduced-motion)·고대비 설정 대응, 채점 결과 음성 안내(aria-live)

## 개발 메모

- 단일 `index.html` PWA, 진도는 `localStorage`(`chainmemo-v1`)에 저장
- 콘텐츠 원본은 리포 밖에 보관하고, 배포본에는 체인 단위로 인코딩해 분리 삽입한다 (콘텐츠 무단 수집 방지 단계 설계의 1단계)
- 푸시 전 `node tests/run-tests.js` 전부 PASS가 먼저
